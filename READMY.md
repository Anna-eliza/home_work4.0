# Домашнее задание 4.0

## Описание проекта
Проект представляет собой систему управления категориями и товарами.

## Реализованный функционал:
1. Созданы классы `Product` (товар) и `Category` (категория).
2. Реализован подсчет общего количества категорий и товаров с помощью атрибутов класса.
3. Написана функция `load_data_from_json` для загрузки данных о категориях и товарах из JSON-файла.
4. Написаны юнит-тесты с использованием `pytest` и фикстур для проверки инициализации классов и корректности подсчета.


## Новые классы-наследники

В проект добавлены два класса, наследующих `Product`:

- **`Smartphone`** — смартфон с атрибутами: производительность (`efficiency`), модель (`model`), объём памяти (`memory`), цвет (`color`).
- **`LawnGrass`** — трава газонная с атрибутами: страна-производитель (`country`), срок прорастания (`germination_period`), цвет (`color`).

## Ограничения операций

- **Сложение** (`+`) разрешено только для продуктов **одного класса**. Попытка сложить смартфон и траву вызовет `TypeError`.
- **Добавление в категорию** (`add_product`) разрешено только для `Product` и его наследников. Любой другой объект вызовет `TypeError`.
